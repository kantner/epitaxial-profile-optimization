# Simulation code for Phys. Rev. Applied 26, 044012 (2026)
This repository contains MATLAB code to reproduce the figures and simulation results presented in the following paper:

A. Thayil, L. Ermoneit, L. R. Schreiber, T. Koprucki and M. Kantner:
<i>Optimization of Si/Si-Ge Heterostructures for Large and Robust Valley Splitting in Silicon Qubits</i>, 
Phys. Rev. Applied <b>26</b>, 044012 (2026)<br />
DOI: <a href="https://doi.org/10.1103/pd5d-sddp">10.1103/pd5d-sddp</a><br />
preprint: <a href="https://doi.org/10.48550/arXiv.2512.18064">arXiv:2512.18064</a>

Simulations were carried out using MATLAB R2023a.
